# Pokemon

Detta är en Pokédex som har skapats i React

Sidan hämtar de första 151 Pokémon från PokéAPI.
Användaren kan välja en Pokémon från en rullista eller
klicka på ett Pokémon-kort för att få mer information
om den, exempelvis typ, längd och vikt.

## Starta projektet

Installera först de paket som behövs:

```bash
npm install
```

Starta sedan projektet:

```bash
npm run dev
```

Öppna länken som visas i terminalen.

## Verktyg och tillägg som används

- React
- JavaScript
- HTML och CSS
- React Router
- Vite
- PokéAPI

## API

Informationen om Pokémon hämtas från:
https://pokeapi.co/
